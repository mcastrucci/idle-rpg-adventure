# Glossary

| Term | Spanish (concept origin) | Meaning |
|---|---|---|
| Actor | — | Engine term for whatever takes part in activities (RPG: the hero) |
| Hub | Hub / lugar principal | Engine area kind where the player prepares; RPG: Sanctuary |
| World map | Mapa global | Engine graph of areas connected by routes |
| Area | Área | Engine term for an explorable place on the world map; RPG: region |
| Route | Ruta / portal | World-map edge with requirements |
| Completion | Completar / conquistar | Engine generic rule; RPG conquest is one configuration |
| Segment | Segmento | Unit of an expedition timeline revealed over time |
| Simulator plugin | — | Game-provided pure function that simulates an expedition |
| Sanctuary | Santuario | Starting settlement and social hub |
| The Fracture | La fractura | Interdimensional rift connecting fragments of universes |
| Ark | Arca | Evacuation ship of ancient humanity |
| Guardian | Guardián | Extraordinary entity guarding some passages/portals |
| Region | Región | Explorable fragment made of connected locations |
| Location | Ubicación | One illustrated scene/node in a region |
| Conquest pool | — | Ordinary locations that count toward the 70% conquest rule |
| Conquest | Conquista | Personal, permanent completion of a region; unlocks idle |
| Live Adventure | Aventura live | Active, instanced exploration and combat |
| Idle Expedition | Expedición idle | Server-side automatic simulation in a conquered region |
| Instance | Instancia | Private live session for a solo player or a party |
| Run bag | Loot no asegurado | Loot gained in a live run, lost to the corpse on death |
| Escrow | — | Consumables reserved by an active expedition |
| Corpse | Cuerpo / contenedor | Recoverable container left at the place of death |
| Activity lock | — | `activity_state` guaranteeing one main activity per character |
| Ledger | — | Append-only record of every economy change |
| Tick | Tick | Combat time unit (provisional 500 ms) |
| Telegraph | Ataque anunciado | Boss windup visible before it resolves |
| Automation rules | Reglas de combate automático | Ordered condition→action list driving auto combat |
| Settlement | Liquidación | Granting/consuming everything at expedition end |
| `engineVersion` / `contentHash` | — | Versions recorded with every simulation |
