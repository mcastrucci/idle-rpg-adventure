# Spec: Declarative Content Format

> Status: **Draft v0.1**. Decision: [ADR-0008](../adr/0008-declarative-content-pipeline.md),
> [ADR-0014](../adr/0014-tiled-scene-editor.md).

## 1. Layout

```
content/
  regions/
    <region_slug>/
      region.json
      locations/<location_slug>.json
      scenes/<location_slug>.tmj        # Tiled map: background image layer + object layers
      art/                              # source art (compressed variants generated by pipeline)
  enemies/*.json
  skills/*.json
  items/*.json
  loot-tables/*.json
  encounter-tables/*.json
  progression/xp-curve.json
```

## 2. IDs

- Namespaced, lowercase snake: `region:verdant_hollow`, `loc:verdant_hollow.old_well`, `enemy:thornback_boar`,
  `skill:cleave`, `item:minor_healing_potion`, `loot:boar_common`.
- Never renamed, never reused. Removing content = `"deprecated": true`.

## 3. Examples (illustrative)

### region.json
```json
{
  "id": "region:verdant_hollow",
  "name": "Verdant Hollow",
  "difficulty": 1,
  "recommendedLevel": [1, 6],
  "startLocation": "loc:verdant_hollow.portal_clearing",
  "mandatoryBosses": ["enemy:hollow_matriarch"],
  "conquest": { "requiredDiscoveries": 7, "frozenAt": "2026-12-01" },
  "idle": { "activities": ["idle:hunt", "idle:gather"] }
}
```

### location.json
```json
{
  "id": "loc:verdant_hollow.old_well",
  "region": "region:verdant_hollow",
  "kind": "ordinary",
  "conquestPool": true,
  "scene": "scenes/old_well.tmj",
  "exits": [
    { "id": "north", "to": "loc:verdant_hollow.portal_clearing" },
    { "id": "down", "to": "loc:verdant_hollow.well_bottom", "requires": { "item": "item:rope" } }
  ],
  "encounters": "enc:verdant_hollow.well",
  "resources": [{ "node": "res:glowcap", "lootTable": "loot:glowcap_gather" }],
  "hotspots": [{ "id": "inscription", "type": "lore", "textKey": "lore.old_well.inscription" }]
}
```

Hotspot/exit **geometry** lives in the Tiled `.tmj` (object name = hotspot/exit ID); gameplay data lives in JSON. The
compiler checks both sides match.

### skill.json
```json
{
  "id": "skill:shield_bash",
  "cooldownTicks": 8,
  "windupTicks": 0,
  "targeting": "enemy",
  "effects": [
    { "type": "damage", "coeffBp": 8000, "school": "physical" },
    { "type": "taunt", "duration": { "value": 3, "unit": "attacks" } }
  ]
}
```

## 4. Compiler (`tools/content-cli`)

Commands: `validate`, `build` (→ `dist/content-bundle.json` + `contentHash`), `graph <region>` (Mermaid diagram),
`schema` (JSON Schema export).

Checks:
- Zod schema per file.
- Referential integrity for every ID reference.
- Region graph: all locations reachable from `startLocation`; ≥ `requiredDiscoveries` conquest-pool locations reachable
  without secret-only exits; mandatory bosses placed in some location.
- Tiled ↔ JSON consistency (every exit/hotspot has geometry and vice versa).
- Frozen conquest baseline unchanged for published regions.
- Art budget: background dimensions and compressed size within limits (from spike 2).

## 5. Localization

User-facing strings referenced by keys (`textKey`) in `content/i18n/<lang>.json`; English first.
